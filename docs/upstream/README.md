# Upstream documentation

Тут збережено документацію з PixelBoard, щоб не змішувати її з документацією
цього проєкту:

* `PIXELBOARD-README.md` — головний README PixelBoard (опис фіч, інсталяція).
* `PATCH-MODULE-README.md` — README модуля `pixelboard-patches` (як збирати
  upstream-бандл).
* `PIXELBOARD-RELEASE-NOTES.md` — нотатки релізу 1.2.0.

Актуальна документація цього проєкту — у `README.md` та `docs/*.md`.
